\begin{abstract}
Musculoskeletal disorders are among the main causes of disability, according to the World Health Organization. This study aims to develop a tool capable of determining abnormalities in musculoskeletal radiographs. The proposed model is a transformer-based deep neural network with a multiple-view fusion module to integrate multiple radiographic projections, mimicking how radiologists interpret radiographic views. The model was trained and tested on the MURA dataset (Stanford), a large open-access dataset combining 40,561 radiographic images of the upper extremity from multiple studies. The model achieved an accuracy of XX (to be determined). The results are expected to demonstrate the benefit of multi-view integration for improving diagnostic performance and robustness in musculoskeletal abnormality detection. 
\end{abstract}

\subsection{Dataset}

For this project, we worked with the MURA dataset (Musculoskeletal Radiographs) released by the Stanford Machine Learning Group. It contains upper-limb radiographs labeled as normal or abnormal at the study level. In total, the dataset includes 40\,561 images grouped into 14\,656 studies. We followed the official split provided by the authors, which gave us 36\,808 images for training (13\,457 studies) and 3\,197 images for validation (1\,199 studies). 

A study corresponds to a single patient examination and can contain between one and four radiographic views depending on the body part examined (for example: elbow, finger, forearm, hand, humerus, shoulder or wrist). Since the goal is binary classification (normal vs abnormal), each study has a single label, even if it contains several images. The dataset is also slightly imbalanced, with around 38.5\% abnormal studies.

To formalize the data, we write:
\begin{equation}
\mathcal{D} = \{ (S_i, y_i) \}_{i=1}^{N},
\end{equation}
where $S_i = \{ x_i^{(v)} \}_{v=1}^{n_i}$ is the $i$-th study, $n_i \in \{1,2,3,4\}$ is the number of views available, and $y_i \in \{0,1\}$ is the study-level label.

We implemented a custom PyTorch dataset class (\texttt{data/dataset.py}) to load the studies, handle the fact that the number of views varies, and return both the images and a mask indicating which views are present.

\subsection{Preprocessing and Data Augmentation}

Before being passed to the model, all images were converted to three channels and resized to $224 \times 224$ pixels so that they match the input size expected by the Vision Transformer. We also normalized the pixel intensities using the standard ImageNet normalization.  

During training, we applied several data augmentation steps (defined in \texttt{data/transforms.py}) such as random horizontal flips, small rotations and slight contrast adjustments. These augmentations help the model generalize better because radiographs can vary a lot in terms of acquisition conditions. For a study $S_i$, each image is transformed as:
\begin{equation}
\tilde{x}_i^{(v)} = T(x_i^{(v)}), \quad v = 1,\dots,n_i.
\end{equation}

Because studies do not always contain four views, we padded missing views to obtain a fixed-size tensor of shape $[4, 3, 224, 224]$. We also created a binary mask $m_i \in \{0,1\}^{4}$ indicating which views are real and which are padding.

\subsection{Model Architecture}

The model is based on a multi-view classification approach. The intuition is that radiologists rarely rely on a single projection when evaluating an X-ray, so our model should be able to combine several views at once. The architecture is composed of three main parts: (1) a shared Vision Transformer backbone, (2) a fusion module based on cross-attention, and (3) a final classification layer.

\subsubsection{Vision Transformer Backbone}

Each view is processed independently with the same Vision Transformer (ViT-Base Patch16-224), implemented in \texttt{models/vit\_backbone.py}. The model was initialized with ImageNet pretraining. For each view $\tilde{x}_i^{(v)}$, the backbone produces a feature vector of size 768 using the class token:
\begin{equation}
h_i^{(v)} = f_{\theta}(\tilde{x}_i^{(v)}) \in \mathbb{R}^{768}.
\end{equation}

For each study, we collect the feature vectors from all available views and stack them into a matrix:
\begin{equation}
H_i =
\begin{bmatrix}
h_i^{(1)} \\
\vdots \\
h_i^{(V_{\max})}
\end{bmatrix}
\in \mathbb{R}^{V_{\max} \times d},
\end{equation}
with padded rows for missing views. The same backbone is used for every image in the dataset.

\subsubsection{Cross-Attention Multi-View Fusion}

Since the number of images per study varies, we use a cross-attention module (\texttt{models/multiview\_fusion.py}) to fuse the view embeddings into a single representation. The idea is that the model can learn to focus more on informative views and ignore padded ones.

We introduce $Q$ learnable query tokens $Q_0 \in \mathbb{R}^{Q \times d}$ and compute queries, keys and values as:
\begin{align}
Q_i &= Q_0 W_Q, \\
K_i &= H_i W_K, \\
V_i &= H_i W_V.
\end{align}

We then apply attention over the views, while masking padded positions:
\begin{equation}
A_i = \mathrm{softmax}\left( \frac{Q_i K_i^{\top}}{\sqrt{d_k}} + M_i \right),
\end{equation}
and derive the fused representation:
\begin{equation}
U_i = A_i V_i.
\end{equation}

When $Q = 1$, the result is directly a single feature vector; otherwise, we average the $Q$ outputs:
\begin{equation}
z_i = \frac{1}{Q} \sum_{q=1}^{Q} U_i^{(q)} W_O.
\end{equation}

\subsubsection{Classification Head}

The final representation $z_i$ is passed through a dropout layer and a fully connected layer followed by a sigmoid activation:
\begin{equation}
\hat{y}_i = \sigma\left(w^{\top} \mathrm{Dropout}(z_i) + b\right),
\end{equation}
where $\hat{y}_i \in (0,1)$ is the predicted probability that the study is abnormal.

\subsection{Training Procedure}

To deal with the class imbalance, we used a weighted binary cross-entropy loss:
\begin{equation}
\mathcal{L} = - \frac{1}{B} \sum_{i=1}^{B} 
\left[ w_{+} y_i \log(\hat{y}_i) 
+ w_{-} (1 - y_i) \log(1 - \hat{y}_i) \right].
\end{equation}

Training was performed with the AdamW optimizer using a typical learning rate of $10^{-4}$ and weight decay $10^{-4}$. The training loop (\texttt{training/trainer.py}) computes the loss, updates the weights, evaluates the model on the validation set at each epoch, and saves checkpoints using \texttt{training/checkpoint\_manager.py}. Mixed precision and gradient accumulation could be enabled depending on GPU memory.

\subsection{Evaluation Metrics}

We evaluated the model mainly with the AUC-ROC score, since it is commonly used in medical imaging for binary classification. We also report accuracy, sensitivity and specificity. For a given threshold $\tau$, these metrics are defined as:
\begin{align}
\mathrm{Accuracy} &= \frac{\mathrm{TP} + \mathrm{TN}}{\mathrm{TP} + \mathrm{TN} + \mathrm{FP} + \mathrm{FN}}, \\
\mathrm{Sensitivity} &= \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FN}}, \\
\mathrm{Specificity} &= \frac{\mathrm{TN}}{\mathrm{TN} + \mathrm{FP}}.
\end{align}

AUC-ROC is computed from the ROC curve by varying $\tau$ across $[0,1]$.

\subsection{Model Interpretability}

To visualize what the model focuses on, we used a Grad-CAM approach adapted for transformers (\texttt{evaluation/visualization.py}). We compute gradients of the abnormality score with respect to intermediate feature maps and use them to produce attention heatmaps:
\begin{equation}
\alpha_c = \frac{1}{HW} \sum_{u=1}^{H} \sum_{v=1}^{W}
\frac{\partial s}{\partial F_{cuv}},
\end{equation}
\begin{equation}
L_{\mathrm{GradCAM}} = \mathrm{ReLU}\left( \sum_{c=1}^{C} \alpha_c F_c \right).
\end{equation}

For multi-view studies, we generate one map per view, which helps assess whether the model attends to relevant anatomical regions.
